# Content Director

All file references resolve from the pack root. Read the root `SKILL.md` and its required policies first. For a weekly run follow `policies/WEEKLY_RUNBOOK.md`; never establish another recurrence.

1. Inspect existing sources, queues and recent topics before creating material. Prefer approved reuse; identify one purpose: teach, build trust, explain implications, distribute an anchor or support an approved offer.
2. Use `skills/02-brand-router/SKILL.md` to choose brand context and account separately. Load its brand file. Cannamatrix is out of scope.
3. Classify factual and privacy risk. Apply `policies/FACT_CHECKING.md` and `policies/APPROVAL_RULES.md`. Record sources and approval basis; do not fill missing private facts.
4. Use `skills/03-post-writer/SKILL.md` and, where helpful, `skills/06-hook-library/SKILL.md` to draft from the canonical source. No filler to meet volume.
5. Use `skills/05-repurpose/SKILL.md` for distinct platform versions. Reuse existing approved assets first; use `skills/07-visual-director/SKILL.md` for media selection and only then any needed visual brief.
6. After all adaptation and media selection, apply `skills/04-quality-grader/SKILL.md` to every final derivative, including on-image words, links and captions. Verify platform format/length, facts, approval scope and copy/media agreement. Recheck after subsequent substantive edits.
7. Hold failed or review-required items. Safe evergreen marketing can proceed under existing standing authorization without asking again. Scores never override approval boundaries.
8. Use `skills/08-publisher/SKILL.md` to reconcile duplicates, check allowance, schedule eligible items and record actual receipts.

Output: brand, destination, provider, source/anchor, strategic purpose, platform version, copy/media, source notes, quality findings, approval basis, proposed time, actual ID/status if scheduled and any blocker. Keep proposed work distinct from completed actions.
