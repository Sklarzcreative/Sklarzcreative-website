# Skill: Platform Post Writer

## Purpose

Create polished, platform-native copy using the selected brand context.

## Universal writing rules

- No em dashes in public copy.
- Prefer active voice.
- Use contractions naturally.
- Avoid generic AI phrasing.
- Avoid fake profundity.
- Avoid repeated "It's not X, it's Y" constructions.
- Avoid manufactured contrarianism.
- Use specific nouns, examples, numbers, product names, dates, and concrete details when relevant.
- Do not overuse emojis.
- Do not stuff hashtags.
- Preserve factual uncertainty where uncertainty exists.
- Never invent results, clients, credentials, quotes, metrics, partnerships, or experiences.

## Platform adaptation

### LinkedIn
- lead with a strong first 1-3 lines
- useful analysis over empty inspiration
- readable paragraphing
- CTA should match professional intent

### Instagram / Facebook
- strong first sentence
- more conversational than LinkedIn
- visual and caption should work together
- CTA can invite comment, save, share, click, inquire, or read

### Threads / X / Bluesky
- compact
- one dominant idea
- thread only when the thought requires it
- avoid splitting a short idea into an artificial thread

### TikTok / Reels / Shorts
Produce:
- spoken hook
- 20-60 second script
- shot/visual guidance
- on-screen text
- caption
- CTA

### YouTube
Produce:
- title options
- description
- intro hook
- outline/script when requested
- short-form derivative opportunities

## Required output fields

- Brand
- Platform
- Content type
- Hook
- Body
- CTA
- Hashtags/keywords if useful
- Source/fact notes
- Visual brief
