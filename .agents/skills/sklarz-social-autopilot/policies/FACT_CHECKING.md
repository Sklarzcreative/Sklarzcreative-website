# Fact-Checking Standard

## Trigger

Fact-check before publication when a post contains material claims about:
- current products
- launches
- pricing
- company actions
- APIs
- platform support
- laws/regulations
- research
- scientific findings
- statistics
- benchmarks
- dates
- quotes
- health/wellness claims
- news

## Source preference

1. primary source
2. official documentation
3. original research/paper
4. reputable first-hand reporting
5. high-quality secondary analysis

## Required behavior

- separate verified fact from interpretation
- preserve caveats
- record source links/notes with the content item
- do not rely on a social post as the sole source when an original source exists
- never invent a citation
- if a material claim cannot be verified, rewrite or remove it
